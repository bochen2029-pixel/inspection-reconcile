# Limitations

This file states what is verified, what is synthetic, and what is unsupported. It is updated as steps complete.

## Data
All fixtures, examples and reports describe the fictional North Creek project (NC-001). No real organization's data
is used.

## Quickbase
The adapter is built from Quickbase's published JSON API contract (SPEC §12.1). Until step C3 runs against an
authorized test app, the connector is tested only against a mock transport.
